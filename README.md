## 📌 Curation Rules

This catalogue aims to stay useful instead of becoming a random link dump.

**Included:** AI-native software, agent frameworks, coding agents, model/API platforms, MCP servers, skills, AI automation, RAG/knowledge systems, observability, AI security, self-hosted AI and closely related developer infrastructure.

**Popularity:** GitHub repositories are ordered primarily by current GitHub Stars within their category.

**Editorial selection:** 🏆 is assigned manually based on practical relevance, ecosystem importance, originality, breadth of use, or particularly strong developer value.

**Freshness:** Star badges are live, but the ordering is a point-in-time popularity snapshot. Re-check periodically as fast-moving projects can change dramatically.

**Quality over quantity:** Generic software with no meaningful AI relationship is deliberately excluded.
